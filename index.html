Skin Mask Mobile v3

Mosaic, Blur, or TV Static. Designed for illustrations, game characters, and photos. Image processing runs in your browser.

Detection: experimental illustration-aware color grouping; not a trained character segmentation model.

If detection misses an area, tap that area on the image to add a similar-colored connected region. Tap again to add more. This is an assistive correction, not guaranteed automatic segmentation.

Illustration detection uses color and connected regions, not a trained AI model. It can miss stylized skin or cover similarly colored clothing and backgrounds. Tap missed regions and inspect the result carefully.
